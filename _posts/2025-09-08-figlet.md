# Requirements
Kali linux terminal


# Commands to get this running

Install figlet and lolcat

sudo apt install figlet lolcat

figlet "Uzair FTW"

figlet -c "Uzair FTW"

figlet -c "Uzair FTW" | lolcat

showfigfonts

figlet -f slant -c "Uzair FTW" | lolcat

figlet -f big -c "Good day ahead" | lolcat

figlet -f slant -c "Uzair FTW" | lolcat && figlet -f big -c "Good day ahead" | lolcat

sudo nano ~/.zshrc
in the bottom of the file paste figlet -f slant -c "Uzair FTW" | lolcat && figlet -f big -c "Good day ahead" | lolcat


## Conclusion

This can also be used to display banners for servers or custom messages
